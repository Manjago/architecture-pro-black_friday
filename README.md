# Проектная работа: Масштабирование E-commerce "Мобильный мир"

Этот репозиторий содержит решения для проектной работы 4-го спринта по курсу "Архитектура ПО: продвинутый уровень". Цель проекта — спроектировать и реализовать масштабируемую архитектуру для e-commerce приложения, способную выдерживать пиковые нагрузки ("Черная пятница").

Работа выполнена в формате "Infrastructure as Code" и "Documentation as Code". Каждое задание реализовано в отдельной директории и содержит собственное `README.md` с подробными инструкциями.

## Структура решений по заданиям

*   **[Задание 2: Шардирование](./mongo-sharding/)**
    *   **Цель:** Реализация базового шардирования MongoDB.
    *   **Технологии:** Docker Compose, MongoDB (mongos, config server, shards).
    *   👉 **[Перейти к README и инструкции по запуску](./mongo-sharding/README.md)**

*   **[Задание 3: Репликация](./mongo-sharding-repl/)**
    *   **Цель:** Добавление отказоустойчивости (High Availability) путем репликации каждого шарда.
    *   **Технологии:** MongoDB Replica Set.
    *   *Директория будет создана в процессе выполнения задания.*

*   **[Задание 4: Кеширование](./sharding-repl-cache/)**
    *   **Цель:** Ускорение часто выполняемых запросов с помощью кеширования.
    *   **Технологии:** Redis, паттерн Cache-Aside.
    *   *Директория будет создана в процессе выполнения задания.*

## Итоговое решение для проверки
